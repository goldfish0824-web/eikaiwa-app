# 02 学生版 共通仕様（Claude版・Gemini版の両方に適用）

学生版は、画面と学習の流れを共通の部品（`shared/student-core/`）で作り、AIエンジンだけを差し替える。エンジンごとの違いは `03_student_claude.md` と `04_student_gemini.md` に書く。

## 1. 狙い

- 「何を言えばいいか分からない」「言いたいことが英語にならない」「聞き取れない」を、ヒント・日本語サポート・ゆっくり再生で乗り越えさせる。
- 評価や点数は出さない。**できたことを認め、次に試す言い方を1つだけ**伝える。

## 2. 画面構成

1. **ログイン画面**：パスワード入力と注意事項の確認（文言はエンジンごとに異なる。各版の仕様書を参照）。
2. **シナリオ選択画面**：カテゴリ別のカード。各カードに難易度と所要時間（約5分）、挑戦回数。
   - 2026-10-26：シナリオのデータに難易度の項目がないため、難易度は選んだレベルで表し、カードには「そのレベルでの往復数・約5分・挑戦回数」を表示する。挑戦回数は「会話をはじめる」を押した回数。
3. **レベル選択**：各版で定義したレベルから選ぶ。端末に記憶。
4. **今日のフレーズ画面**
5. **ロールプレイ画面**
6. **ふりかえり画面**
7. **使い方と注意**ページ
8. **相談先**画面（安全フラグ `support` のときに表示）

## 3. 学習の流れ

### 3.1 今日のフレーズ（約1分）
- シナリオごとに3つのキーフレーズ（シナリオデータの `key_phrases`）。
- 英語・日本語訳・「聞く」ボタン・「言ってみる」ボタン。
- 言ってみた結果は、文字起こしとフレーズが大まかに一致すれば「OK!」を表示（単語の一致率で判定。厳密にしない）。何度でもやり直せる。スキップ可能。

### 3.2 ロールプレイ（レベルに応じて6〜10往復）
- 画面上部に「場面」「あなたの役」「相手（AI）の役」「ゴール」を日本語で表示。
- AI の発言は読み上げる。字幕は初期表示ありで、オン・オフできる。
- 生徒はマイクボタンを押して話す（押して話し、もう一度押すか無音で終了）。
- 下部の補助ボタン：
  | ボタン | 動作 |
  |---|---|
  | ヒント | 生徒のレベルに合った返答例を3つ表示（短い順）。タップすると読み上げる |
  | 日本語で言う | 生徒が日本語で話す → 英語の言い方を表示・読み上げ → 生徒が英語で言い直す |
  | もう一度 | AI の直前の発言をゆっくり読み上げる |
  | 和訳 | AI の直前の発言の日本語訳を表示 |
  | やり直す | 直前の自分の発言と AI の返答を取り消して、言い直す |
- ヒントと和訳は毎回の返答に含めて受け取るので、ボタンを押しても通信は発生しない。
- AI は生徒の誤りをその場で指摘しない。自然な言い直し（recast）を自分の返答に含めるだけにする。
- ゴールを達成するか、往復数の上限に達したら AI が会話を締める。
- 実装で足したこと（2026-10-26）：
  - 今日のフレーズを画面上部に小さく表示し、会話の中で使えたら ✓ を付ける（タップで読み上げ）。
  - 「やり直す」で取り消した自分の発言は、キーボード入力のときは入力欄に戻す。
  - 「終了」を押すと「ふりかえりへ／ふりかえりをしないでホームへ／会話をつづける」を選ばせる。
  - 画面の下に「相手は AI です。個人が特定される情報は話さないでね」を常に表示する。
  - 通信に失敗したら、送ろうとした文を残したまま「もう一度試す」を出す。上限（429）のときは会話を続けさせない。

### 3.3 ふりかえり（日本語）
- **できたこと**：2つ（具体的に）
- **次はこう言ってみよう**：1つ（生徒の発言 → より良い言い方 → 理由）
- **今日のフレーズ**：会話の中で使えたかのチェック
- **発音のポイント**：Gemini版のみ（`04_student_gemini.md`）
- 「もう一度挑戦」「別のシナリオへ」ボタン

## 4. 保存するデータ

- 端末内（localStorage）：選んだレベル、字幕設定、各シナリオの挑戦回数、端末ID、パスワード（次回から自動でログインするため。上級者版と同じ。「ログアウト」で消える）。
- 会話内容・音声は保存しない（ページを閉じたら消える）。
- サーバー（Worker）：パスワードIDごと・端末IDごとの1日の利用回数と、安全フラグの件数のみ。

## 5. 安全対策（共通）

`06_terms_safety.md` の対策を実装すること。共通の要点：
- AI と話していることの明示
- 個人情報（フルネーム・住所・電話番号・学校名・SNS など）を話さないよう注意喚起し、AI も聞かない（自己紹介ではニックネームを使う）
- シナリオから外れた話題・不適切な話題は、やさしく会話に戻す（`safety_flag: "redirect"`）
- 悩みや危険のサインがあれば、会話練習を中断して相談先を案内する（`safety_flag: "support"` → 相談先画面）

## 6. 共通部品とエンジンの分担

| 共通部品（student-core）が担当 | エンジンが担当 |
|---|---|
| 画面の表示と遷移、シナリオ・レベルの選択 | 生徒の発話を受け取る（ブラウザ認識 or 録音） |
| 会話履歴の管理（最大20往復） | AI の返答・ヒント・和訳の取得 |
| ボタンの動作、字幕、挑戦回数 | 読み上げ |
| フレーズの一致判定 | ふりかえりの取得 |
| `safety_flag` に応じた画面遷移 | 「日本語で言う」の処理 |

エンジンの共通インターフェースは `05_architecture.md` に定義する。
