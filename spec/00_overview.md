# 00 全体概要

## 1. 目的

英語の「知識」はあるが「話す経験」が足りない学習者が、AI 相手に毎日気軽に英会話を練習できるようにする。市販アプリ（Speak など）と同様の学習体験を、API を組み込んだ自作アプリで低コストに実現する。

## 2. 利用場面

1. 開発者本人の英会話学習（上級者版）
2. 英会話力を伸ばしたい高校生への配布・自習用（学生版 Claude版）
3. 大学生など18歳以上の学生への配布・自習用（学生版 Gemini版）

## 3. 3つのアプリ

### 上級者版（advanced）— Gemini Live API
- **対象**：TOEIC900点超・英検1級レベル。長期留学の経験はない。18歳以上。
- **弱点の想定**：知識ではなく、反応の速さ・言い回しの自然さ・雑談の続け方・議論での切り返し・ネイティブの速さと割り込みへの対応。
- **方式**：リアルタイム音声対話。
- **学習の流れ**：ウォームアップ（前回の表現を使う）→ 会話（5〜10分）→ 言い直しレポート → 表現の復習。

### 学生版（student）— 画面と流れは共通、エンジンが2種類
- **学習の流れ**：今日のフレーズ → ロールプレイ（ヒント・日本語サポートあり）→ 日本語でのふりかえり。
- **方式**：ターン制（生徒が話す → AI が返答）。

| | Claude版（student-claude） | Gemini版（student-gemini） |
|---|---|---|
| 対象 | 高校生（英検3級〜2級程度） | 大学生など18歳以上の学生（英検準2級〜準1級程度） |
| 音声認識 | ブラウザ（Web Speech API） | Gemini が録音した音声を直接理解 |
| 返答の生成 | Claude API | Gemini API |
| 読み上げ | ブラウザ（speechSynthesis） | Gemini TTS（ブラウザの読み上げにも切り替え可） |
| 発音のポイント | 扱わない | ふりかえりで1〜2点伝える（参考程度） |
| シナリオ | `data/scenarios_hs.json` | `data/scenarios_univ.json` |
| レベル | やさしい／ふつう | やさしい／ふつう／チャレンジ |

## 4. 全体方針（決定事項）

- 学習の中心は「表現を知る → 練習 → ロールプレイ → フィードバック → 復習」の流れ。自由会話だけのアプリにしない。
- 学生版では ABC などの評価・点数を出さない（AIの判定はぶれるため）。できたことと、次に試す言い方を1つ伝える。
- **18歳未満が使うアプリに Gemini API は使わない**（利用規約上の制限。`06_terms_safety.md`）。高校生向けは Claude版のみ。
- 学生版の2つは同じ画面・流れのコードを共有し、AIエンジンだけを差し替える（`05_architecture.md`）。ただし公開は別の URL・別のパスワードで行う。
- 上級者版の音声エンジンも、将来の差し替え（他社のリアルタイム音声 API）に備えてアダプター層に分ける。
- API キーはすべて Cloudflare Workers に置く。
- 会話の中身・音声はサーバーに保存しない。上級者版の復習データはブラウザ内（localStorage）に保存し、JSON で書き出し・読み込みできるようにする。
- フロントエンドは GitHub Pages、ビルド工程なしの HTML/JS。
- すべてのアプリをパスワードで利用制限し、パスワードごと・端末ごと・全体で1日の利用上限を設ける。

## 5. 未決事項（開発しながら決める）

| 項目 | 選択肢・メモ |
|---|---|
| アプリ名 | 3つを別名にするか、共通名＋サブ名にするか |
| 上級者版の Live モデル | 通常版と「じっくり考える版（Extended Thinking）」を比べる。初期値は応答の速い通常版 |
| 上級者版のレポート生成モデル | 初期値は Gemini（同じキーで完結）。言い直しの質に不満があれば Claude に切り替えられるようにしておく |
| 学生版 Gemini版の読み上げ | Gemini TTS（自然・有料）を初期値に、ブラウザ読み上げ（無料）に切り替え可能。費用と待ち時間を見て決める |
| 学生版 Claude版の音声 | ブラウザの音声認識・読み上げで不都合があれば、音声部分だけ OpenAI の API に差し替える（開発者の判断で依頼） |
| 会話履歴の保存 | 当面は保存しない。「今日のフレーズ」だけ保存できる形を検討 |
| 教員向けの利用状況画面 | 当面なし（回数カウンターと安全フラグの件数のみ）。必要になったら追加 |
| 他の教員への配布版 | 各教員が自分の API キーを入れて使う形。高校で配布するなら Claude版のみ |
