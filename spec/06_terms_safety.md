# 06 利用規約と安全対策

> 規約は変わることがあるので、実装時と公開前に必ず最新版を確認する。

## 1. 各 API の利用規約上の条件

### Gemini API（上級者版・学生版 Gemini版）
- 利用者は18歳以上であること。また、**18歳未満を対象とする、または18歳未満が利用する可能性が高いアプリ・サービスで Gemini API を使わないこと**が定められている。
- したがって：
  - 上級者版（開発者本人・大人の学習者向け）：使用できる。
  - 学生版 Gemini版：**18歳以上の学生（大学生など）だけに配布する場合に限り**使用できる。
  - 高校生向け：**使用できない**（学生版 Claude版を使う）。
- 無料枠では送信内容が Google のサービス改善に使われるため、**課金を有効にしたプロジェクトのキー**を使う。
- 参照：https://ai.google.dev/gemini-api/terms

### Claude API（学生版 Claude版。上級者版のレポートを Claude にする場合も）
- Anthropic は、所定の安全対策を実施することを条件に、未成年が直接やりとりする製品に API を組み込むことを認めている。
- 求められる主な対策：
  1. 想定した利用者だけが使えるようにする仕組み（本アプリではパスワードによる利用制限）
  2. 不適切・有害な内容を防ぐためのモデレーションとフィルタリング
  3. 問題を把握して対応するための報告・監視の仕組み
  4. 安全で責任ある使い方についての案内
  5. **AI と対話していることの明示**
  6. Anthropic が提供する子ども向けの安全用システムプロンプトがある場合は、それを組み込む
  7. 未成年の保護に関する現地の法令を守る
- 参照：https://support.claude.com/en/articles/9307344

### OpenAI API（現時点では使わない。Claude版の音声部分を差し替える場合の候補）
- 保護者の同意があれば未成年の利用が認められている（OpenAI Services Agreement 3.3(c)）。保護者の同意は取得済み。
- あわせて、未成年向けのガイダンスで、法令の順守、年齢に合った説明、内容のフィルター、監視とエスカレーションの仕組み、最新の上位モデルの利用などが求められている。
- 使う場合は、保護者の同意書の範囲に OpenAI（海外の事業者に音声・テキストが送られること）が含まれているかを確認する。
- 参照：https://developers.openai.com/api/docs/guides/safety-checks/under-18-api-guidance

### 共通
- 学校の生徒に配布する前に、管理職への相談や学校の方針（端末の利用ルール、外部サービスの利用ルール）の確認を行う。
- 大学生に配布する場合は、配布先の大学・授業担当者の方針も確認する。

## 2. アプリごとの「18歳未満を入れない」対策

| アプリ | 対策 |
|---|---|
| 上級者版 | 初回に「18歳以上向け」の確認。URL・パスワードを生徒向けの資料に載せない |
| 学生版 Gemini版 | ログイン時に「18歳以上です」へのチェックを必須にする。パスワードは18歳以上の学生にのみ配布。高校生向けのページからリンクしない。Worker で `student-gemini` 以外のパスワードを拒否 |
| 学生版 Claude版 | Gemini を呼ぶコードを含めない。Worker で `student-claude` のパスワードは Gemini 系エンドポイントを拒否 |

## 3. 学生版の安全対策（両版共通・実装必須）

### 3.1 利用の制限
- 教員が配布したパスワードがないと使えない。
- パスワードは学年・期間ごとに変更できるようにする（`PASSWORDS` の追加・削除だけで運用できる形）。

### 3.2 明示と注意喚起
- ログイン画面に注意事項を表示し、確認させる（文言は `03_student_claude.md` / `04_student_gemini.md`）。
- 「使い方と注意」ページを用意する（AI であること、個人情報を話さないこと、AI が間違えることがあること、困ったら先生に相談すること、アプリの使い方）。

### 3.3 AI 側のルール（システムプロンプトに含める）
`prompts/student_turn_claude.md` / `prompts/student_turn_gemini.md` の Safety rules を参照。要点：
- 個人情報を聞かない（自己紹介のシナリオで「何と呼べばいいか」を聞くのは可。ニックネームでよい）。生徒が話してしまったら、触れずに会話を続け、ふりかえりで「個人情報は話さないようにしよう」と伝える。
- 恋愛・性的な内容、暴力、差別、飲酒・喫煙・薬物、政治・宗教の議論には応じず、やさしくシナリオに戻す。
- AI は自分を「英会話練習用のAI」として振る舞い、人間のふりをしない。個人的な関係（友達・恋人など）を築こうとしない。
- 秘密にすることを求めない。会話の外で会う・連絡を取る約束をしない。
- 悩み・危険・自分を傷つけたい気持ちなどのサインがあれば、ロールプレイを中断し、日本語でやさしく、信頼できる人に相談するよう伝える。アプリ側はこの応答を受けたら会話を終了し、相談先の画面を表示する。

### 3.4 相談先の画面
- Claude版（高校生）：担任・保護者・スクールカウンセラーへの相談を促し、子ども向けの公的な相談窓口（例：文部科学省の「24時間子供SOSダイヤル」）を掲載する。
- Gemini版（大学生）：大学の学生相談室などへの相談を促し、公的な相談窓口を掲載する。
- **電話番号・URL は公開前に公式サイトで確認して掲載する。**

### 3.5 Worker 側の対策
- 入力の長さ制限（1発言300文字、履歴20往復、音声30秒、読み上げテキスト400文字）。
- クライアントからプロンプト本文を受け取らない（シナリオIDとレベルのみ）。
- モデルの出力を JSON として検証し、形式が崩れていたら安全な定型文に差し替える。
- `safety_flag` の件数を数える（内容は保存しない。`05_architecture.md` 10）。
- 会話内容・音声をログに残さない。

### 3.6 ターン JSON の安全フィールド
```json
"safety_flag": "none" | "redirect" | "support"
```
- `none`：通常
- `redirect`：不適切・話題外だったので会話をシナリオに戻した
- `support`：悩み・危険のサイン。アプリは会話を終了し、相談先の画面を表示する

## 4. 上級者版の注意

- 会話内容をサーバーに保存しない。
- 大人向けだが、生徒がアクセスする可能性を下げるため、上級者版の URL やパスワードを生徒向けの資料に載せない。
