# 01 上級者版 機能仕様（Gemini Live API）

## 1. 対象と狙い

- TOEIC900点超・英検1級レベル、長期留学の経験なし、18歳以上。
- 鍛えたいのは「反応の速さ」「自然な言い回し」「雑談の続け方」「議論での切り返し」「速い英語・割り込みへの対応」。
- 文法の誤りを直すことより、**文法的には正しいが教科書的・不自然な表現**を、ネイティブらしい言い方に置き換えることを重視する。

## 2. エンジン

- 会話：Gemini Live API（ネイティブ音声）。2026年10月時点の候補は **Gemini 3.8 Live**（2026年9月に正式提供開始）。モデル名は `worker/config.js` で管理し、実装時に公式ドキュメントで確認する。
- 「じっくり考える版（Extended Thinking）」もあるが、応答が遅くなるため初期値は通常版。設定で切り替えて比較できるようにする。
- レポート：Gemini のテキストモデル（Flash 系）。Claude に切り替え可能にしておく。
- 接続・音声形式・割り込み処理はアダプター層（`shared/audio/` と `advanced/live-adapter.js` など）に分け、将来ほかの会社のリアルタイム音声 API に差し替えられるようにする。

## 3. 画面構成

1. **ログイン画面**：パスワード入力。初回のみ「18歳以上向け」の確認と、AI と話していることの表示。
2. **ホーム画面**
   - 今日の復習フレーズの数（例：「復習 5件」）
   - モード選択（4種類）
   - 会話の長さ（5分／10分）
   - 設定ボタン
3. **会話画面**
   - 大きな「開始／終了」ボタン、残り時間、マイクの入力レベル表示
   - AI が話している／聞いている状態の表示
   - 字幕（自分と AI の発話の文字起こし）の表示・非表示切り替え（初期値：非表示。聞き取りの練習のため）
   - 「今の発言をもう一度」ボタン
   - 「一時停止」ボタン（マイク入力の送信を止める。無音の課金を減らす）
   - 「イヤホンなしで使う」チェック（AI の発話中は自分の声を送らない。`05_architecture.md` 5.2。2026-10-25 追加）
   - 相手（ペルソナ）と話題の表示（接続後）
4. **レポート画面**（会話終了後に自動表示）
5. **フレーズ帳画面**（保存した表現の一覧と復習）
6. **設定画面**

## 4. モード

詳細な話題・場面は `data/adv_modes.json` に定義する。

### 4.1 Small Talk（雑談）
- 同僚・友人・初対面の相手との雑談。
- AI は質問攻めにせず、自分の話もする。話題を自然に切り替える。相づち・リアクションを多用する。
- ユーザーの答えが短すぎる場合は、掘り下げる質問で話を広げさせる。

### 4.2 Discussion（議論）
- 英検1級の二次試験のような社会問題（例：AI と雇用、地方の過疎化）。
- AI はユーザーの立場を聞いたうえで反対の立場を取り、根拠や具体例を求め、反論する。
- 最初に「今日の話題」を画面に表示する。

### 4.3 Role-play（場面練習）
- 仕事や生活の具体的な場面（例：ALT との授業の打ち合わせ、海外の学会での雑談、ホテルでの苦情）。
- 画面に「あなたの役」「相手の役」「達成すること」を表示する。途中で予想外の展開が1回入る。

### 4.4 Quick Response（瞬発トレーニング）
- AI が短い質問や発言を次々に投げ、ユーザーが即座に返す。
- AI の質問のあと約4秒黙ったら、アプリが `[NEXT]` を送り、AI が次の質問に進む（無音の判定はクライアント側。`05_architecture.md` 5.4）。
- 目的は「完璧な文」より「止まらずに返す」こと。

## 5. 設定項目

| 項目 | 選択肢 | 初期値 |
|---|---|---|
| 話す速さ | ふつう（ネイティブ同士）／速め | ふつう |
| くだけ具合 | 丁寧／カジュアル／スラング・イディオム多め | カジュアル |
| 割り込み | なし／あり（AI が話の途中で割り込むことがある） | なし |
| 会話中の訂正 | しない／さりげなく言い直す（recast） | しない |
| AI の声 | Live API の音声から数種類 | 未定 |
| 字幕の初期表示 | 表示／非表示 | 非表示 |
| Live モデル | 通常版／じっくり考える版 | 通常版 |

設定は localStorage に保存し、会話開始時にシステムプロンプトへ反映する（`prompts/adv_live_system.md`）。

## 6. 会話の流れ

1. **ウォームアップ（最初の1〜2分）**：フレーズ帳の「今日の復習」から最大3つを選び、AI がそれらを使いたくなる流れを作る。使えたかどうかは会話後のレポートで判定する。
2. **本編**：選んだモードで会話。
3. **終了**：時間切れ、または終了ボタン。終了30秒前にクライアントから `[WRAP_UP]` を送り、AI が自然に会話を締める。

## 7. 言い直しレポート

会話終了後、文字起こしを Worker の `/adv/report` に送り、テキストモデルで生成する（Live API は JSON の構造化出力に対応していないため、別の呼び出しで作る）。

### 表示内容
1. **言い直し（最大8件）**：自分の発言 → より自然な言い方 → なぜそう言うか（日本語で1〜2行）→ 種類（不自然／誤り／もっと簡潔に／場面に合った丁寧さ／語彙）
2. **使えていた良い表現（2〜3件）**
3. **覚えたいチャンク（最大5件）**：AI が使った表現のうち、ユーザーが使えると便利なもの
4. **ウォームアップ表現の使用チェック**
5. **数値**（クライアント側で計算）：自分の発話時間の割合、1分あたりの語数（WPM）、最長の沈黙
6. 各項目に「フレーズ帳に保存」ボタン

出力形式は `prompts/adv_report.md` に定義した JSON に従う。

## 8. フレーズ帳と復習

- 保存した表現を localStorage に保存。各項目は「元の発言」「自然な言い方」「説明」「保存日」「復習段階」を持つ。
- 復習はライトナー方式（段階1:翌日、2:3日後、3:7日後、4:14日後、5:30日後）。
- 復習の方法は2つ：
  1. **フレーズ帳での復習**：日本語の説明を見て自然な言い方を声に出す → 答えを見て自己判定（できた／まだ）。
  2. **会話でのウォームアップ**（6-1）。会話で使えたら段階を1つ上げる。
- JSON で書き出し・読み込み（端末の変更やバックアップ用）。

## 9. 制限

- 1回の会話は最長10分（Live API の接続時間と文字起こしの安定性のため）。
- 1日の利用上限は Worker 側で設定（`07_cost_limits.md`）。
