# 03 学生版 Claude版 仕様（高校生向け）

共通部分は `02_student_common.md`。ここには Claude版に固有のことだけを書く。

## 1. 対象

- 日本の高校生（英検3級〜2級程度）。18歳未満を含む。
- 教員が配布したパスワードで使う自習用アプリ。
- **Gemini API は一切使わない**（`06_terms_safety.md`）。

## 2. エンジンの構成

| 役割 | 使うもの |
|---|---|
| 音声認識 | ブラウザの Web Speech API（`SpeechRecognition`、`lang="en-US"`。「日本語で言う」のときは `"ja-JP"`） |
| 返答・ヒント・和訳・ふりかえり | Claude API（Worker 経由。初期値は Claude Haiku 5.5） |
| 読み上げ | ブラウザの `speechSynthesis` |

- 音声認識が使えない端末・マイクを拒否した場合は、キーボード入力に自動で切り替える。
- ブラウザの音声認識は、発音が多少不正確でも「ありそうな文」に直して認識する。そのため Claude版は**発音の評価はしない**（会話の流れの練習に特化）。
- 音声認識・読み上げの品質に問題があれば、音声部分だけ OpenAI の API（文字起こし・音声合成）に差し替える可能性がある。エンジン内で「認識」「読み上げ」を差し替えやすい作りにしておく。

## 3. 発話の受け取り方

1. マイクボタンを押すと認識開始。話している途中の文字を表示（`interimResults=true`）。
2. 話し終わると認識結果を表示し、「送る」「言い直す」を選ばせる（ブラウザの誤認識をその場で直せるように）。
3. 「送る」で Worker の `/sc/turn` にテキストを送る。

iOS Safari 特有の不具合（認識が止まらない・結果が重複する等）に対処する。過去作（Web Speech API を使った英単語ゲーム）での対処法を流用してよい。

## 4. 読み上げ

- 英語（en-US / en-GB）の声から、端末で使える最も自然な声を選ぶ（声の候補の優先リストを持つ）。
- 速度はレベルに応じて設定（`data/scenarios_hs.json` の `levels`）。「もう一度」は 0.75。
- iOS では最初の読み上げをタップ操作の中で行う必要がある。

## 5. レベル

| | やさしい | ふつう |
|---|---|---|
| 目安 | 英検3級〜準2級 | 準2級〜2級 |
| AI の英語 | 中学〜高1レベルの語彙、1回の発言は1〜2文 | 高校レベルの語彙、1回の発言は2〜3文 |
| 読み上げ速度 | 0.85 | 0.95 |
| 往復数の目安 | 6往復 | 8〜10往復 |

## 6. シナリオ

`data/scenarios_hs.json` の12本（自己紹介、ALTとの雑談、週末と趣味、部活動、修学旅行先での注文・おみやげ・道案内・現地校との交流、ホテルのトラブル、落とし物、日本の紹介、将来の夢）。

## 7. ログイン画面の注意事項

> これは AI との会話練習です。相手は人間ではありません。
> フルネーム・住所・電話番号・学校名・SNS のアカウントなど、個人が特定される情報は話さないでください（自己紹介ではニックネームを使いましょう）。
> AI の答えが間違っていることもあります。困ったことがあれば先生に相談してください。

確認ボタンを押すまで先に進めない（「上の注意を読みました」にチェックするまで「ログイン」が押せない）。

## 8. Worker のエンドポイント

`/sc/turn`、`/sc/summary`（`05_architecture.md`）。プロンプトは `prompts/student_turn_claude.md` と `prompts/student_summary.md`。

## 9. 公開

- URL 例：`https://goldfish0824-web.github.io/eikaiwa-app/student-claude/`
- この版の配置物（HTML・JS）に Gemini 用のエンジンのコードを含めない。
  - `test/student-claude-isolation.test.js` で、`student-claude/index.html` から読み込まれるファイルに Gemini のコード・`/sg/`・`/adv/`・18歳以上向けのページへの参照がないことを確かめている。

## 10. 実装メモ（2026-10-26）

- ファイル：`student-claude/index.html`・`app.js`（エンジンを選んで共通部品に渡す）・`texts.js`（注意事項・使い方・相談先の文言）。エンジンは `shared/engines/claude-engine.js`。
- 聞き取った文は編集できる入力欄に出し、「送る」「言い直す」を選ばせる（誤認識をその場で直せる）。キーボード入力のときは確認なしで送る。
- 「使い方と注意」には、声はブラウザ（端末）の音声認識で文字にすること（ブラウザによっては端末・ブラウザの会社のサーバーに送られること）、AI（Anthropic の Claude）には文字だけを送ること、会話はサーバーに保存しないことを書いた。
- 12シナリオ・2レベルとも最初から使えるようにした（フェーズ5の項目を前倒し）。
- 費用の目安は `?cost=1` を付けて開いたときだけ表示する（開発者の確認用）。
