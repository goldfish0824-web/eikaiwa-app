# 04 学生版 Gemini版 仕様（大学生など18歳以上向け）

共通部分は `02_student_common.md`。ここには Gemini版に固有のことだけを書く。

## 1. 対象

- 大学生など**18歳以上**の学生（英検準2級〜準1級程度）。
- 教員が配布したパスワードで使う自習用アプリ。
- **18歳未満には使わせない。** 高校生向けの資料・ページからリンクしない。高校で配布する場合は Claude版を使う（`06_terms_safety.md`）。

## 2. エンジンの構成

| 役割 | 使うもの |
|---|---|
| 音声認識＋返答・ヒント・和訳 | Gemini API（録音した音声をそのまま送り、1回の呼び出しで「文字起こし＋返答＋ヒント＋和訳」を JSON で受け取る） |
| ふりかえり | Gemini API（テキスト） |
| 読み上げ | Gemini TTS（初期値）。設定でブラウザの `speechSynthesis` に切り替え可能 |

- モデルは `worker/config.js` で管理する。2026年10月時点の候補（第三者サイトの情報。実装時に公式で確認）：
  - ターン：Flash-Lite 系（例：gemini-3.1-flash-lite。速くて安い）。品質不足なら Flash 系（例：gemini-3-flash）
  - ふりかえり：Flash 系
  - 読み上げ：gemini-3.1-flash-tts-preview
- JSON は Gemini の構造化出力（レスポンススキーマ指定）で受け取る。
- 将来、Live API を使ったリアルタイム会話モードを追加できる（フェーズ8・任意）。

## 3. 発話の受け取り方

1. マイクボタンを押すと録音開始（`shared/audio/` の AudioWorklet で 16kHz・16bit・モノラルの PCM を取得）。入力レベルを表示。
2. もう一度押すか、約1.5秒の無音で録音終了。最長30秒。
3. PCM を WAV 形式に変換し、Base64 で Worker の `/sg/turn` に送る（ブラウザごとに録音形式が異なる問題を避けるため、MediaRecorder ではなく WAV に統一する）。
4. 返ってきた `user_transcript`（AI が聞き取った生徒の発言）をチャット欄に表示し、続けて AI の返答を表示・読み上げる。
5. 聞き取りが違っていた場合は「やり直す」で直前の往復を取り消して言い直す。

- 録音が短すぎる（0.5秒未満）・無音の場合は送信せず「声が聞き取れませんでした」と表示する。
- 「日本語で言う」は、日本語の音声を録音して `/sg/turn`（`action: "ja2en"`）に送る。

## 4. 読み上げ（Gemini TTS）

- AI の返答テキストが届いたら、すぐに Worker の `/sg/tts` に送って音声を取得し、再生する。
- 話す速さはレベルに応じて TTS への指示文で調整する（例：「ゆっくりはっきり」）。「もう一度」はさらにゆっくり。
- 生成した音声はその会話の間だけメモリに保持し、「もう一度」で同じ速さなら再利用する。
- TTS が失敗したら、自動でブラウザの読み上げに切り替える。
- 設定で「読み上げ：Gemini（自然な声）／ブラウザ（速い・無料）」を選べる。

## 5. 発音のポイント

- Gemini は生徒の声を直接聞くため、聞き取りにくかった語を指摘できる。
- 各ターンの応答に、**意味が伝わりにくくなるほどの発音の問題があった場合だけ** `pronunciation_note_ja`（1件まで）を含める。細かいなまりは指摘しない。
- クライアントはそれを会話の間ためておき、ふりかえりのときにテキストとして送る。ふりかえりで「発音のポイント」を最大2件表示する。
- 「AI による判定なので参考程度にしてください」と表示する。点数・評価は出さない。

## 6. レベル

| | やさしい | ふつう | チャレンジ |
|---|---|---|---|
| 目安 | 英検準2級 | 英検2級 | 英検準1級 |
| AI の英語 | 基本語彙、1回1〜2文 | 高校〜大学初級の語彙、1回2〜3文 | 自然な口語表現も使う、1回2〜4文 |
| 読み上げ | ゆっくりはっきり | ややゆっくり | 自然な速さ |
| ヒント | 短い完全な文 | 理由・具体例つき | 自然な言い回し・つなぎ言葉を含む |
| 往復数の目安 | 6往復 | 8往復 | 10往復 |

## 7. シナリオ

`data/scenarios_univ.json` の12本（留学生との交流会での自己紹介、サークル・ゼミの紹介、アルバイト先での接客、留学生のキャンパス案内、空港のチェックイン、海外のレストラン、ホテルのトラブル、乗り換えをたずねる、教授への質問、寮のルームメイトとのルール決め、日本の話題について意見を言う、インターンの英語面接）。

## 8. ログイン画面の注意事項

> このアプリは **18歳以上の方** 向けです。18歳未満の方は利用できません。
> これは AI との会話練習です。相手は人間ではありません。あなたの声は、返答の生成のために Google の AI サービスに送られます（サーバーには保存しません）。
> フルネーム・住所・電話番号・SNS のアカウントなど、個人が特定される情報は話さないでください。
> AI の答えや発音の指摘が間違っていることもあります。

「18歳以上です」と「上記を確認しました」の2つにチェックするまで先に進めない。

## 9. Worker のエンドポイント

`/sg/turn`、`/sg/tts`、`/sg/summary`（`05_architecture.md`）。プロンプトは `prompts/student_turn_gemini.md` と `prompts/student_summary.md`。
**これらのエンドポイントは、アプリ種別が `student-gemini` のパスワードでのみ受け付ける。**
