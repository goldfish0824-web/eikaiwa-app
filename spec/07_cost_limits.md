# 07 費用の目安と利用制限

> 単価は2026年10月時点で調べた値（一部は第三者サイトの情報）。**変わりやすいので、実装時・公開前に公式の料金ページで必ず確認する。** 円換算は1ドル＝150円で概算。

## 1. 上級者版（Gemini Live API）

### 単価の目安
- Gemini 3.8 Live：音声入力 約0.005ドル／分、音声出力 約0.018ドル／分。ユーザーと AI が半分ずつ話すと約0.012ドル／分。
- 注意点：
  - 無音の時間も課金される（接続している間ずっと音声を送るため）。
  - 会話の履歴がターンごとに再課金されているようだ、という開発者の報告がある。長い会話ほど割高になる可能性。
  - じっくり考える版（Extended Thinking）は単価が異なる可能性がある。要確認。

### 概算
| 項目 | 金額 |
|---|---|
| 1回10分の会話（目安） | 約0.12ドル（約18円） |
| 履歴の再課金を考慮した場合 | 約30〜80円 |
| レポート生成（Gemini Flash 系） | 約1円 |
| **1日30分×30日** | **約1,600円〜（再課金しだいで増える）** |

### 費用を抑える工夫
- 1回の会話は最長10分。短い会話を複数回のほうが履歴の再課金が少ない。
- 話していない時間は「一時停止」でマイク入力の送信を止める。
- フェーズ1で、会話ごとのトークン使用量を記録し、Google Cloud の請求額と照らし合わせて実際の単価を確認する。

## 2. 学生版 Claude版（Claude Haiku 5.5・高校生）

### 単価の目安
- 入力 0.10ドル／100万トークン、出力 0.50ドル／100万トークン（プロンプトが10万トークン以下の場合）。
- プロンプトキャッシュの書き込み（5分）0.125ドル、読み込み 0.01ドル（入力単価の10%）。システムプロンプトをキャッシュする（最小キャッシュ長は512トークン）。
- 2026-10-26 に公式の料金ページで確認し、`worker/config.js` の `claudePricingUsdPerMTokens` に入れた。Worker は呼び出しごとの費用の目安（`costJpy`）を返すので、`?cost=1` で開くと画面で確かめられる。

### 概算
| 項目 | 前提 | 金額 |
|---|---|---|
| 1往復 | 入力約2,500トークン、出力約300トークン（＋思考分） | 約0.1円 |
| 1シナリオ | 往復10回＋日本語で言う等3回＋ふりかえり1回 | 約1.5〜2円 |
| 1学年で使った場合 | 40人 × 週3回 | 週あたり約200〜250円 |

### 応答速度の工夫
- Haiku 5.5 は思考（adaptive thinking）が既定で有効。会話の応答では effort を低めにして待ち時間を短くする。
- temperature などのサンプリング設定は指定しない（Haiku 5.5 の推奨）。

## 3. 学生版 Gemini版（大学生・18歳以上）

### 単価の目安（第三者サイトの情報。要確認）
| モデル | 用途 | 単価 |
|---|---|---|
| gemini-3.1-flash-lite | ターン | テキスト入力 0.25ドル、音声入力 0.50ドル、出力 1.50ドル（各100万トークン） |
| gemini-3-flash | ふりかえり（ターンで品質不足の場合も） | テキスト入力 0.50ドル、音声入力 1.00ドル、出力 3.00ドル |

- 音声入力は1秒あたり32トークン（1分で約1,900トークン）。

### 1シナリオの概算
| 内訳 | 前提 | 金額 |
|---|---|---|
| 生徒の音声 | 合計約2分 | 約0.3円 |
| ターンのテキスト入出力 | 13回 | 約2.5円 |
| ふりかえり | 1回 | 約0.5円 |
| 読み上げ（Gemini TTS） | AI の発話 合計約2分 | 約9円 |

## 4. 利用制限（Worker で実装）

| 対象 | 上級者版 | 学生版 Claude版 | 学生版 Gemini版 |
|---|---|---|---|
| パスワードごと／日 | 40分（一時トークン発行時に加算） | 3,000往復 | 2,000往復 |
| 端末ごと／日 | — | 80往復 | 80往復（読み上げ回数は別に200回） |
| 全体／日（安全装置） | 60分 | 5,000往復 | 3,000往復 |
| 1回の長さ | 最長10分 | 最大20往復 | 最大20往復・音声30秒 |

- 日付の切り替えは日本時間0時。
- 上限に達したら 429 と日本語メッセージを返す。
- カウンターは Cloudflare KV（`USAGE`）に `日付:パスワードID` と `日付:パスワードID:端末ID` のキーで保存し、数日で自動削除（TTL）する。
- 学生版の安全フラグの件数（`日付:パスワードID:#flag:フラグ`）は、運用で見返せるよう30日で自動削除する（2026-10-26 決定）。
- 学生版は「上限の確認 → AI の呼び出し → 成功したら加算」の順。AI の呼び出しに失敗したら加算しない。

## 5. 予算の安全装置

- Google Cloud の請求先アカウントで**予算アラート**を設定（例：月3,000円で通知）。上級者版と学生版 Gemini版が同じキーなら合算で見る。必要ならプロジェクトを分けて、アプリごとの費用を見えるようにする。
- Anthropic のコンソールで月の利用上限を設定。
- Worker の全体上限（上表）で、万一パスワードが広まっても費用が膨らまないようにする。
